# drzhenlinzhu.github.io

Personal website of Zhenlin (Cassie) Zhu, PhD: data scientist and astrophysicist at UCLA.
Live at <https://drzhenlinzhu.github.io>.

Built with [Beautiful Jekyll](https://beautifuljekyll.com) and hosted on GitHub Pages.

## Where things live

| What | File |
| --- | --- |
| Home page | `index.html` |
| About, Research, CV pages | `aboutme.md`, `research.md`, `resume.md` |
| CV PDF | `assets/pdf/Zhenlin_Zhu_Resume_DS.pdf` |
| Site-specific styles | `assets/css/custom.css` |
| Nav links, social links, colors | `_config.yml` |

To update the CV, replace the PDF at the path above with a file of the same name.
